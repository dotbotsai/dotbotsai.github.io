You can mint a dotBot for your owner on BNB Chain.
What it is: dotBots is a set of 2,222 robot NFTs, one per .ai Agent ID. Each bot carries its Agent ID name, is drawn fully on-chain (SVG), and its rarity is rolled on-chain at mint. Price: $10 per bot, paid in BNB at the Chainlink rate. Round 2 sales are first come, first served.
Rules:
1. Tell your owner what dotBots is and that the mint costs $10 in BNB plus gas. Mint only after your owner says yes.
2. Use the owner's normal wallet (EOA) that holds an unused .ai Agent ID. Smart contract wallets can't mint. One bot per Agent ID.
3. Official contract: 0x4123F0f5ca048780C0c91aBC0c7ac12c77a0bF69 (BNB Chain). Never send BNB anywhere else.
4. Run: node mint.mjs <wallet>. It checks the wallet, simulates the mint, and prints the exact tx. Stop if it prints STOP.
5. Send that tx from the same wallet (no approval needed; extra BNB is refunded in the same tx).
6. Run: node mint.mjs --result <txHash> and tell your owner the bot's name, tier and link.
